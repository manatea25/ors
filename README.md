# ORS — Observation and Recording System

Інтерактивний адаптивний прототип системи спостереження та фіксації.

## Запуск

Проєкт не потребує збірки або встановлення залежностей. Відкрийте `index.html` або запустіть будь-який статичний сервер:

```bash
python -m http.server 8080
```

Після цього відкрийте `http://localhost:8080`.

Для публікації скопіюйте `index.html`, `styles.css` та `app.js` у кореневу папку сайту. Прототип використовує зовнішні CDN для карти, іконок, шрифтів і демонстраційних стокових фотографій.

## Демо-доступи

- Адмін: `111` / `111`
- Агент: `agent` / `111`
- Гість: `guest` / `111`

Це демонстраційний клікабельний прототип. Дані зберігаються лише в пам’яті вкладки браузера і скидаються після перезавантаження сторінки.
